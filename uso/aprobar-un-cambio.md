# Aprobar o rechazar un cambio

Puedes decidir desde el **correo** o directamente desde el **tablero**. En los dos casos la decisión se toma en el tablero, con tu sesión.

{% tabs %}
{% tab title="Desde el correo" %}
{% stepper %}
{% step %}
### Abre el correo del corte

Llega uno por dominio cuando hay propuestas o alertas. Cada propuesta muestra el objetivo, el nivel actual y el propuesto, la regla que la disparó, la evidencia y la etiqueta del dato.
{% endstep %}

{% step %}
### Pulsa Aprobar o Rechazar

El botón **no decide nada todavía**. Solo abre la página de confirmación en el tablero.
{% endstep %}

{% step %}
### Inicia sesión

Si no tienes la sesión abierta, el tablero te la pide y luego te devuelve a la propuesta.
{% endstep %}

{% step %}
### Confirma

Revisa la información y confirma. Si vas a rechazar, escribe el **motivo**; es obligatorio.
{% endstep %}
{% endstepper %}
{% endtab %}

{% tab title="Desde el tablero" %}

### Entra a Mis aprobaciones

Verás las propuestas **pendientes** de tus dominios y las que ya se **decidieron**.
{% endstep %}

{% step %}
### Abre una propuesta

Revisa la evidencia y los indicadores, acciones y riesgos ligados al objetivo.
{% endstep %}

{% step %}
### Decide

**Aprobar**, o **Rechazar** con motivo.
{% endstep %}

## Qué pasa después

| Decisión | Efecto |
| --- | --- |
| **Aprobar** | Se crea una versión nueva del nivel del objetivo, con fecha, aprobador y evidencia. El tablero muestra el nuevo nivel y el cambio queda en el historial. |
| **Rechazar** | El nivel no cambia. Se guarda el motivo y quién rechazó. |

## Mensajes que puedes ver

| Mensaje | Qué significa |
| --- | --- |
| *Solo el titular o el suplente de … deciden esta propuesta.* | No eres aprobador de ese dominio. |
| *Eres suplente: podrás decidir si el titular no responde en 2 cortes.* | Eres suplente, pero el titular todavía está a tiempo. |
| *La propuesta ya está aprobada / rechazada.* | Otra persona ya decidió. |
| *El nivel vigente cambió desde que se propuso; la propuesta caducó.* | El nivel cambió por otra decisión. La propuesta ya no aplica. |
| *Para rechazar hay que escribir el motivo.* | Falta el motivo. |
